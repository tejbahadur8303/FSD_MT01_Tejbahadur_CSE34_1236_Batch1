# Library Book Management API (Set A)

REST API built with **Node.js** and **Express.js**. All records are stored in a
JavaScript array in server memory (no database). Data resets when the server restarts.

## Setup and Run

```bash
npm install
node server.js
```

The server starts on **http://localhost:3000** and prints a message in the terminal.
To use another port: `PORT=4000 node server.js`

## Record Structure

| Field         | Type    | Description                         |
|---------------|---------|-------------------------------------|
| id            | Number  | Unique id generated by the server   |
| title         | String  | Title of the book                   |
| author        | String  | Name of the author                  |
| genre         | String  | Book category or genre              |
| publishedYear | Number  | Year of publication                 |
| available     | Boolean | Whether the book is available       |

## Endpoints

| # | Method | URL                              | Success | Errors |
|---|--------|----------------------------------|---------|--------|
| 1 | GET    | /api/books                       | 200     |        |
| 2 | POST   | /api/books                       | 201     | 400    |
| 3 | GET    | /api/books/:id                   | 200     | 404    |
| 4 | PUT    | /api/books/:id                   | 200     | 400, 404 |
| 5 | DELETE | /api/books/:id                   | 200     | 404    |
| 6 | GET    | /api/books/filter?author=value   | 200 (empty array if no match) | 400 if author missing |

`/api/books/filter` is declared before `/api/books/:id` so that "filter" is not treated as an id.

## Sample Request Bodies

POST `/api/books`
```json
{
  "title": "The Discovery of India",
  "author": "Jawaharlal Nehru",
  "genre": "History",
  "publishedYear": 1946,
  "available": true
}
```

PUT `/api/books/102`
```json
{
  "title": "The Alchemist - Revised Edition",
  "author": "Paulo Coelho",
  "genre": "Fiction",
  "publishedYear": 1988,
  "available": true
}
```

## Testing

Test with Postman or Thunder Client. Save screenshots in the `screenshots/` folder.
Cases to test: all 6 endpoints, invalid id (404), invalid body (400),
filter with a matching author and with an author that has no matches.
